# Aulas Python 🎓🐍

Este repositório foi criado para armazenar e organizar todos os códigos de exemplo, estudos conceituais e anotações práticas desenvolvidos ao longo do aprendizado da linguagem Python.

O conteúdo aqui presente é baseado nas lições teóricas e nos exemplos práticos do **Curso em Vídeo**, ministrado pelo professor Gustavo Guanabara.

## 🚀 Conteúdos Estudados

* **Fundamentos da Linguagem:** Variáveis, tipos primitivos, entrada e saída de dados.
* **Operadores e Estruturas:** Operações aritméticas, estruturas de controle condicional (`if/elif/else`).
* **Estruturas de Repetição:** Laços de repetição controlada e condicional (`for` e `while`).
* **Manipulação de Dados:** Análise textual, tratamento de strings e formatação avançada.

## 🛠️ Tecnologias Utilizadas

* **Python 3.x**
* Ambiente de desenvolvimento / IDE utilizado nos estudos

## 📂 Estrutura do Repositório

O projeto está organizado da seguinte forma:

* `CursoEmVideo/`: Pasta principal que armazena os scripts explicativos, divididos de forma cronológica conforme o progresso nos módulos e mundos do curso.

## 💻 Como Explorar os Arquivos

Para rodar os exemplos das aulas na sua máquina local, siga os passos abaixo:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Navegue até o diretório do curso:**
   ```bash
   cd Aulas-Python/CursoEmVideo
   ```

3. **Execute o script desejado via terminal:**
   ```bash
   python nome_da_aula.py
   ```
